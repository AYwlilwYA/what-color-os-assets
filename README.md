# 赞助名单云端资源

模块设置页「已赞助」区块从这里拉取，**头像不打进 APK**。

## 文件

| 路径 | 说明 |
|---|---|
| `sponsors.txt` | 名单，一行一人 |
| `<name>.jpg` / `.png` | 头像图片，与名单同目录 |

## 名单格式

```
首字母|名字
首字母|名字|头像
```

- `首字母`：头像拉不到时显示的圆底文字，必填。
- `名字`：显示名，建议脱敏（如 `K***`）。
- `头像`：可省。填**同目录文件名**（`sponsor_kokoro.jpg`）或**完整 https 直链**。
  只允许字母数字与 `_ . -`，禁止路径分隔符与 `..`；非 https 协议一律忽略。

`#` 开头为注释行，空行忽略。

## 头像规格

- 建议 192×192、≤100KB（客户端上限 512KB，超限不显示）。
- 客户端会自动居中裁方 + 圆形裁切，源图不必预先裁圆。
- 本地缓存 24 小时；换图后**改文件名**可让所有客户端立刻生效（同名需等缓存过期）。

## 客户端行为

- 名单拉取失败 → 整块隐藏，不影响设置页其它功能。
- 头像拉取失败 → 显示首字母圆底。
- 全部请求在子线程，5s 连接 / 5s 读取超时。
